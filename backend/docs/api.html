Monitoring Service API

REST API для получения метрик серверов и работы с отчётами

Base URL: /api

Содержание

Серверы Метрики Отчёты Статус сервиса Политика отказоустойчивости

Политика отказоустойчивости

Сервис зависит от базы данных: без успешного подключения к БД он не запускается. После старта продолжает отслеживать состояние зависимостей.

  • При старте без БДсервис не стартует и завершает работу с ошибкой подключения к базе
  • Список серверовисточники метрик берутся из таблицы servers в БД; для каждого сервера запускается отдельный опрос TCP-источника
  • При потере БД в runtimeэндпоинты, зависящие от БД, могут возвращать 503; состояние смотрите через GET /api/status
  • При потере TCP-источникасборщик для конкретного сервера автоматически переподключается, пока сервис запущен
  • Наблюдаемостьтекущее состояние смотрите через GET /api/status

Ошибки

При ошибке возвращается JSON:

{
  "error": "описание ошибки"
}

Для временной недоступности БД используется статус 503 Service Unavailable.
